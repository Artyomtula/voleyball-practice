# Сравнение детекторов мяча

Получено командой (из папки `backend`):

```bash
python -m scripts.compare_ball_models <видео> <разметка_мяча.csv>
```

Эталон — покадровая разметка мяча из датасета автора fast-volleyball-tracking
(`Frame, Visibility, X, Y`). Попадание — точка не дальше 9 пикселей от размеченного
мяча при ширине кадра 1920 (так же считает автор в README репозитория).
Время — полное время обработки одного кадра на ноутбуке Apple M1 Pro (CPU),
включая чтение видео.

YOLO26n — это та же модель, что ищет игроков, но с классом COCO «sports ball».
Ролик gtu_20250316_002 входит в обучающую часть датасета автора, поэтому оценка
VballNet на нём может быть завышена; ролики 003 и 005 — из тестовой части.
